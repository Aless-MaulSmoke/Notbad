CONTEXTO

Esta pasta é uma recompilação do Windows Notepad chamada Notbad. O Ghidra
gerou a recompilação e o C bruto; o opencode produziu a versão 1.0 em C++
com o toolset v141 (Visual Studio 2017). Agora iniciamos a versão 1.0.2,
mantendo o visual minimalista do Notepad original e adicionando recursos 
de mini editor de código.
